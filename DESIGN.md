# Design System — El Nour Dashboard

## Mode: Operate
Business dashboard. Scanability, consistency, precision. Brand lives in details.

## Palette
- **Primary/Accent:** Emerald 500-600 (#10b981, #059669)
- **Background:** Stone-50 (light) / Zinc-950 (dark)
- **Surface:** White / Zinc-900
- **Text:** Stone-900 / Stone-50
- **Muted text:** Stone-500 / Stone-400
- **Border:** Stone-200 / Zinc-800
- **Destructive:** Red-500
- **Success:** Emerald-500
- **Warning:** Amber-500
- **Info:** Sky-500

## Typography
- **Font:** Cairo (Arabic) + Inter (Latin fallback)
- **Heading:** 600-700 weight
- **Body:** 400-500 weight
- **Base size:** 14px for UI, 16px for content

## Spacing Scale
- 4px base unit
- Cards: p-5, gap-4
- Sections: space-y-6
- Page padding: p-4 lg:p-6

## Radius
- Cards: rounded-2xl (16px)
- Buttons: rounded-xl (12px)
- Inputs: rounded-xl (12px)
- Badges: rounded-full

## Shadows
- Cards: subtle border + shadow-sm
- Elevated: shadow-md on hover
- Modals: shadow-xl

## Components
- Tables: striped rows, sticky headers, hover states
- Forms: labeled inputs with validation states
- Buttons: primary (emerald), secondary (outline), ghost, destructive
- Badges: pill-shaped with semantic colors
- Modals: centered with backdrop blur
- Toasts: top-right, auto-dismiss
